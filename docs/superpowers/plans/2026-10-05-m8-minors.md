# M8 Deferred Minors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** close the 7 minors the M7 final review deferred.

**Architecture:** small fixes in the existing app, exec and core modules; no new subsystems. Each behaviour fix gets a test that fails first.

**Tech Stack:** Rust, Ratatui, gix, git CLI.

**Spec:** docs/superpowers/specs/2026-10-02-gitty-design.md

## Global Constraints
- Same as M7 (docs/superpowers/plans/2026-10-05-m7-minors.md); nothing here changes them.
- Search, path lookups and range counts run on the 2-thread search pool, never on the readers.

## Review Focus
1. A range note counts exactly the commits the diff holds that are not selected rows, in every scope.
2. Leaving compare always ends with a history commit shown, even when the saved one is gone.
3. A question gitty asks is still true when it opens, and a running git waiting on a prompt is never queued behind one.
4. A network job's result never waits more than one grace period on helpers holding its pipes.
5. Docs and comments say where search runs.

## Tasks
- [ ] **T1 range note by commit set.**
  - The worker streams `rev-list --ignore-missing newest --not oldest^1` and counts the commits not among the selected rows' ids (sent with the request); `Msg::RangeCount` carries that `extra`.
  - A stale cached count is dropped when a new walk starts.
  - Shared `GitCli::run_cancellable` reads stdout on its own thread with a caller's reader (no 60 MB buffer on a kernel-sized range).
  - Test: in all-refs scope, a range whose rows hold a commit outside the diff and whose diff holds two commits outside the rows says "2 more".
- [ ] **T2 compare exit and search bar.**
  - When the walk finishes without finding the commit saved by compare, row 0 is selected and shown.
  - A click on the bottom bar row while the search bar is open keeps it open.
  - Tests: amend away the saved commit during compare, Esc mid-walk, row 0's commit is shown; a click on the bar keeps the typed text.
- [ ] **T3 queued questions.**
  - Credential prompts open before the diverged and stale-lock questions.
  - A queued stale-lock offer opens only if `LockId::of(index.lock) == Some(seen)`; otherwise it is dropped silently.
  - Tests: a prompt queued with a pending lock offer opens first; a lock removed before the offer opens is never asked about.
- [ ] **T4 job wait, routing test, docs.**
  - stdout and stderr share one deadline after git exits (`Collector::finish(deadline)`).
  - The routing test asserts `Request::Search`.
  - The M6 plan constraint, the app search module doc, README bench row and the trace example say "search pool".
  - Tests: Collector stops at a deadline already partly spent; routing assertion.
